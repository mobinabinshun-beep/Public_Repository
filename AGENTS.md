# N.U repository instructions

This repository is part of the N.U project. Before adding or changing any project content:
1. Read the canonical [Cross-repository inventory-first and reuse-first protocol](https://github.com/mobinabinshun-beep/Repository/blob/main/Governance/NU-CROSS-REPOSITORY-INVENTORY-AND-REUSE-FIRST-PROTOCOL-fa.md).
2. Re-enumerate all repositories accessible to the project owner and inspect their relevant trees, branches, history, code, docs, tests, assets, manifests, workflows and interfaces.
3. Search Persian/English synonyms, acronyms, former names and behavior-equivalent implementations before creating anything new.
4. Prioritize reuse, extension, modular refactoring and integration; a parallel clone requires documented evidence that existing assets are absent or unsuitable.
5. Consolidate canonical goals, accepted decisions, dependencies and future vision before proposing new architecture.
6. Record repository inventory, read coverage, searches, existing assets, duplication/conflict map, reuse decision, vision alignment, tests and rollback.

If discovery is incomplete, mark the task BLOCKED — REPOSITORY DISCOVERY INCOMPLETE and continue read-only research only. Preserve owner authority and all applicable project governance.
